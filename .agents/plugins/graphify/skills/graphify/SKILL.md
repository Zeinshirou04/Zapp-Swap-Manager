# Graphify Codebase Knowledge Graph

This skill allows the agent to consult pre-computed AST-based architectural knowledge graphs and reports generated by [Graphify](https://pypi.org/project/graphifyy/) instead of exhaustively grepping or reading files across multiple modules.

## Artifacts in `graphify-out/`

When Graphify runs (`graphify .`), it generates artifacts in `graphify-out/`:

- **`graphify-out/GRAPH_REPORT.md`**: Human- and LLM-readable summary of architecture, central hubs/god nodes, cluster communities, and structural health insights.
- **`graphify-out/graph.json`**: The complete knowledge graph structure containing nodes (files, functions, classes, interfaces), attributes, and directional dependency edges.
- **`graphify-out/graph.html`**: Interactive web visualization (can be viewed by the user in a browser).

## Workflow

1. **Check for existing graph output**:
   - Inspect whether `graphify-out/GRAPH_REPORT.md` or `graphify-out/graph.json` exists in the repository root.
2. **Generate or update graph if missing**:
   - If `graphify-out/` does not exist or files are significantly out of date after major codebase modifications, run:
     ```powershell
     graphify .
     ```
     *(or `python -m graphify .`)*
3. **Analyze codebase architecture**:
   - Read `graphify-out/GRAPH_REPORT.md` first to quickly understand top-level modules, core hubs, and cross-cutting dependencies.
   - For specific symbol-level questions, search or parse `graphify-out/graph.json` to find callers, callees, or module connections before reading raw source code.
