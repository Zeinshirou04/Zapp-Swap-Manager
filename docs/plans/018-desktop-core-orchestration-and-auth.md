# Plan 018: Desktop Core Lifecycle Orchestration and Connection/Auth View

## Goal
Enable the Tauri desktop app to manage the background Core service lifecycle (automatically launching `zapp-core.exe` as a headless background process without opening a black command shell, monitoring its status, and providing restart controls) and provide a polished Login / Connection view supporting both zero-config local auto-pairing and remote connections.

## Scope
Folder: `desktop`
Branch: `feat/desktop-core-orchestration-and-auth`

## Steps
0. **Branch Setup**:
   Ensure local `main` is up to date, then check out the task branch:
   ```bash
   git checkout main
   git pull
   git checkout -b feat/desktop-core-orchestration-and-auth
   ```
1. **Desktop Background Process Manager (Rust / Tauri)**:
   - Add Tauri Rust command `start_core_daemon`: checks if `127.0.0.1:8765` is already listening. If not, spawns `zapp-core.exe` using `Command::new` with Windows flags `CREATE_NO_WINDOW | DETACHED_PROCESS` so no command prompt window appears.
   - Add Tauri command `get_core_status`: returns whether the core process is alive, PID, and port.
   - Add Tauri command `read_local_auth_token`: reads `%APPDATA%\Zapp-Swap-Manager\auth.token` generated by the core daemon for automatic local zero-config pairing.
2. **Dedicated Connection & Login View (`desktop/src/components/ConnectView.tsx`)**:
   - When not connected or unauthorized, render an intuitive Sign In / Connection screen instead of an empty error dashboard:
     - **Local Mode Tab**: Shows local Core status ("Core Service: Not Running" / "Core Service: Active"). Single-click "Start Core & Connect" button that spawns the daemon silently and pairs instantly.
     - **Remote Mode Tab**: Allows remote control of another gaming PC: inputs for Core Host URL (`https://...` or `http://192.168...`) and Bearer Token or Cloudflare Access headers.
     - Connection status indicator with real-time feedback (Checking health, Authenticating, Connected).
3. **App State Orchestration (`desktop/src/App.tsx`)**:
   - Distinguish connection states: `connecting`, `disconnected`, `authenticated`.
   - Once authenticated, cleanly transition into the full Game Dashboard.
   - Top Header shows an active Core status pill with quick actions: `Core: Online (v0.1.0)` with dropdown for `Restart Core` and `Disconnect`.
4. **Verification**:
   - Verify launching desktop without core running triggers the auto-start or allows single-click startup without a console window.
   - Verify local pairing token is read and applied automatically.
   - Run `just check` to ensure all linters, formatting, and tests pass.
