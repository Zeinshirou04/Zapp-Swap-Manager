# Plan 043: Release v0.3.1-beta.4

Bump application and ecosystem versions to 0.3.1-beta.4 across Core, Desktop, Mobile, Relay Server, and CI release workflows.

## Key Changes in v0.3.1-beta.4
- **Intelligent Library Matching**: Smart library pairing ensures non-Steam generic games in custom SSD folders (e.g. `E:\Game`) pair with corresponding HDD master paths (e.g. `O:\Game`) rather than defaulting to Steam libraries.
- **Dedicated Game Detail View**: Full-page game overview with hero cover backdrop, activity stats, directory paths, and quick actions.
- **Game Last Played Activity**: Steam ACF manifest parser extracts `LastPlayed` unix timestamps, exposed via `GET /games` and displayed across game cards and detail view.
- **Media & Captures Placeholder**: Future gallery preview for ShareX and NVIDIA ShadowPlay screenshots and recordings.
- **Modal Close Protection**: Disabled backdrop click dismissals so dialogs only close on explicit "X" or Cancel buttons.
- **Typography & Styling**: Integrated Google Font **Inter** and elevated dialog forms with lively card depth and subtle gradient accents.
- **Uppercase Drive Letter Normalization**: Standardized Windows drive paths to always begin with uppercase drive letters (`D:\`).
- **Media Query Token Auth**: Supported `?token=` parameter for local webview image rendering of custom artwork.
