# Plan 044: Release v0.3.1-beta.5

Bump application and ecosystem versions to 0.3.1-beta.5 across Core, Desktop, Mobile, Relay Server, and CI release workflows.

## Key Changes in v0.3.1-beta.5
- **In-App Updater Cloud Download Fix**: Sanitized asset filenames in release manifest generation so that space-separated names like `Zapp Swap Manager_...` are safely normalized to `Zapp.Swap.Manager_...`, fixing 404 download errors and 0% updater progress stalls.
- **Progress Feedback & Error Retry**: Added early connection progress feedback and explicit retry button on update failures in `UpdateNotification.tsx`.
- **Instant Core Scanning**: Sub-10ms game scan cache in core with manifest size shortcuts.
- **Accurate Projected Evict Free Space**: Correctly preserves existing HDD master copy storage calculations.
- **Game Path & Library Relocation Editor**: Custom games can be relocated dynamically from the Game Settings popup.
- **Combined Directory Path Preview**: Full target paths displayed in Add Non-Steam Game modal.
- **Crisp Light UI Theme**: Default modern light mode with instant theme switcher.
