# Plan 045: Release v0.3.1-beta.6

Bump application and ecosystem versions to 0.3.1-beta.6 across Core, Desktop, Mobile, Relay Server, and CI release workflows.

## Key Changes in v0.3.1-beta.6
- **Real-Time Transfer Progress Tracking**:
  - Live progress tracking (`monitorTransfer`) for all transfer operations (`Backup`, `Evict`, `Promote`, `EvictCustom`, `PromoteCustom`).
  - Active updates in SQLite via `Queue.UpdateProgress` so `/jobs` returns accurate percentages and bytes transferred instead of remaining at 0%.
  - Periodic transfer logging (`slog.Info`) every 5 seconds keeping `/logs` and terminal logs active during large transfers.
- **Settings Unsaved Changes Guard**:
  - Dirty state tracking in `SettingsView` comparing modified settings against initial values.
  - Prevents leaving settings page until changes are saved or discarded.
  - Shake animation and danger banner with quick Discard and Save Changes actions.
- **Streamlined Queue Monitor UI**:
  - Compact row layout replacing empty full-width cards.
  - Shows friendly game names instead of raw app IDs / target paths.
  - Removed redundant status text pills, relying on status icons and badge colors.
- **Bottom-Right Transfer Progress Widget**:
  - Replaced full-width top banner with a floating toast/popup in the bottom-right corner.
  - Clean and unobstructed page views.
- **Stale-While-Revalidate Local Caching**:
  - Games and drives are cached in `localStorage` upon connecting to core.
  - When opening Zapp or restoring from tray, games load instantly with zero blank screen or wait time.
  - Background silent revalidation keeps cache up to date.
