# Plan 046: Release v0.3.1-beta.7

Bump application and ecosystem versions to 0.3.1-beta.7 across Core, Desktop, Mobile, Relay Server, and CI release workflows.

## Key Changes in v0.3.1-beta.7
- **Transfer Auto-Refresh**: Views (Dashboard, Games Library, Game Detail, and Drives) automatically reload game locations (SSD/HDD badges) and drive capacities upon transfer completion (`succeeded`, `failed`, or `cancelled`).
- **Periodic Background Revalidation**: App revalidates games and libraries in the background every 30 seconds to stay in sync with external actions (CLI, mobile).
- **Cover Image Hot-Reload & Cache Busting**: Reactive reset of cover image fallback and error states in `GameCard`, `GameDetailView`, and `GameDetailModal`. Added cache-busting revision support to `getGameCoverUrl` and `resolveCoverUrl` so updated artwork loads immediately without stale HTTP cache.
- **Immediate State Synchronization**: `handleGameUpdated` immediately synchronizes local React state across views when editing game settings or covers.
