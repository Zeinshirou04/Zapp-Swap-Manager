# Plan 048: Release v0.3.1 Stable

Bump application and ecosystem versions to 0.3.1 across Core, Desktop, Mobile, Relay Server, and CI release workflows.

## Key Changes in v0.3.1 Stable
- **Official Brand Assets & Custom Iconography**: Complete integration of official brand SVG assets and custom UI icons (`ZappIcon`, `ZappBrandLogo`) across Desktop titlebar, navigation sidebar, and settings.
- **Publisher Security & Verification Metadata**: Comprehensive publisher identity configured across Windows PE metadata, NSIS installer (`currentUser` mode), macOS bundle, Linux Debian/RPM packages, and Android application manifests to prevent untrusted publisher warnings.
- **Dedicated Android Release Signing Pipeline**: Introduced automated release signing configuration in Gradle and helper scripts (`generate-android-keystore.ps1`, `install-dev-cert.ps1`) for seamless packaging and installation.
- **Robust CI & Release Distribution**: Fixed GitHub release download retry resilience and updated Gradle wrapper/actions for reliable matrix validation across Windows and Linux.
