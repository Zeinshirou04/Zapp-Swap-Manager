# Plan 050: Release v0.3.2 Stable

Bump application and ecosystem versions to 0.3.2 across Core, Desktop, Mobile, Relay Server, and CI release workflows.

## Key Changes in v0.3.2 Stable
- **Official Brand Color Tokens**: Comprehensive integration of official Volt & Ink semantic tokens (`tokens.json` & `zapp-tokens.css`) across Light and Dark themes, supporting system auto-detection and high-contrast accessible palettes.
- **NSIS Installer & Uninstaller Process Termination**: Added `desktop/src-tauri/windows/hooks.nsh` with `NSIS_HOOK_PREINSTALL` and `NSIS_HOOK_PREUNINSTALL` hooks to terminate running background services before files are replaced or removed, eliminating Windows file locks during updates and uninstallation.
- **Custom Installation Mode Support**: Reverted NSIS `installMode` to `both` in `tauri.conf.json` so custom installation folders (e.g. `D:\Programs\Zapp Swap Manager`) and machine-wide installations update and uninstall seamlessly.
- **In-App Updater Active Transfer Guard**: Protected against premature process restarts by disabling updates and alerting users when an active game move or verification job is running.
