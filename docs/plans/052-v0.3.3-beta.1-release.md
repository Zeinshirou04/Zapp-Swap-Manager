# Plan 052: Release v0.3.3-beta.1

Bump application and ecosystem versions to 0.3.3-beta.1 across Core, Desktop, Mobile, Relay Server, and CI release workflows.

## Key Changes in v0.3.3-beta.1
- **Storage Overview Streamlining**: Direct access to Drive Storage & Allocation without redundant summary metric cards.
- **Dedicated Drive Details Page**: Full hardware metrics, empty/used space indicators, path configuration synchronized with setup wizard, and search-filtered per-drive game inventory.
- **Revamped Transfer Queue & History**: Multi-view tabs for Active Queue and Chronological History (newest first) with transferred byte progress and failure diagnostics.
- **Core Service Logging Reliability**: Guaranteed in-memory ring buffer initialization even with Windows log file locks, plus structured transfer execution progress logs.
- **UI Cleanups**: Borderless and unboxed status labels in ActiveTransferBanner and DrivesOverview.
