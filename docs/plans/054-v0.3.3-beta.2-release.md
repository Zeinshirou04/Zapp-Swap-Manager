# Plan 054: Release v0.3.3-beta.2

Bump application and ecosystem versions to 0.3.3-beta.2 across Core, Desktop, Mobile, Relay Server, and CI release workflows.

## Key Changes in v0.3.3-beta.2
- **Notion-Style Hero & Acrylic Banner (`GameDetailView`)**: Full-bleed Steam hero banner behind frosted acrylic glass, portrait `2:3` Grid cover, consolidated Game & Backup Status section, exact date/time in Activity & Runtime, and backgroundless detail sections.
- **Portrait Grid Cards & `Details →` Triggers**: Updated `GameCard` and `DriveDetailView` to portrait `2:3` Steam Grid art, replaced drive detail card swap buttons with `Details →`, shortened drive overview trigger text to `Details →`, and stripped card backgrounds from Drive Detail summary metrics.
- **Configurable Robocopy Transfer Engine**: Added `robocopy_threads` (`/MT:1..128`), `robocopy_retries` (`/R:0..20`), `robocopy_wait_seconds` (`/W:0..60`), and `robocopy_unbuffered` (`/J`) across OpenAPI contract, Core daemon config/driver, and flat backgroundless `SettingsView` sub-sections.
- **Living UI Design Guidelines**: Updated `.agents/skills/zapp-ui-design/SKILL.md` with the "Not Every Card Needs a Background" and Notion hero standards.
