# Plan 058: Release v0.3.3-beta.3

Bump application and ecosystem versions to `0.3.3-beta.3` across Core, Desktop, Mobile, Relay Server, and CI release workflows prior to tagging `v0.3.3-beta.3`.

## Key Changes in v0.3.3-beta.3
- **Transfer Logs, Promote Reliability & Window Capture / Z-Order (Plan 055)**: Fault-tolerant detached service logger (`2000` line ring buffer), live throttled Robocopy stdout streaming, granular `95–99%` verify/manifest progress stages, `409 Conflict` mid-transfer custom-game edit lock, Win32 caption frame subclassing (`HWND_NOTOPMOST` + UIPI warning) for ShareX window selection and background window Z-order.
- **Separate Grid Cover & Hero Banner Artwork (Plan 056)**: Independent `2:3` Grid Cover (`cover_url`) and Hero Banner (`banner_url` -> Steam `library_hero` -> Grid cover fallback) with `ArtworkEditorModal` URL inputs, managed local image uploads (`POST /games/{app_id}/artwork`), and reset actions.
- **Media & Captures: ShareX, NVIDIA ShadowPlay, Viewer & Clipboard Copy (Plan 057)**: Auto-detection of ShareX (`History.db` + `Screenshots\`) and NVIDIA ShadowPlay (`DefaultPathW` + `Videos\NVIDIA`) plus custom whitelisted capture folders, inline **Match Aliases**, opaque ID byte-range media streaming, `CaptureViewerModal` image Lightbox & HTML5 `<video controls>` player, and one-click Windows clipboard image copy via `@tauri-apps/plugin-clipboard-manager`.
