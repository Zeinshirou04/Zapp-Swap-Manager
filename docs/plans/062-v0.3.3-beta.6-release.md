# Plan 062: Release v0.3.3-beta.6

Bump application and ecosystem versions to `0.3.3-beta.6` across Core, Desktop, Mobile, Relay Server, and CI release workflows prior to tagging `v0.3.3-beta.6`.

## Key Changes in v0.3.3-beta.6
- **Media Preview Polish & Navigation Integration (Plan 061)**:
  - Replaced bullet `•` styles on capture source badges with crisp brand SVG icons (`sharex`, `shadowplay`, and `custom-folder`).
  - Removed black background from lightbox/modal viewport and adapted modal pop-up width to content-fitting dimensions (`width: fit-content`).
  - Integrated Previous (`<`) and Next (`>`) navigation buttons directly inside `CustomImageViewer`'s floating control pill beside zoom controls.
  - Minimalist modal header strictly displaying Title, Date, Size, Image count (`X / Y`), Details toggle, Copy Image, and Close.
  - Isolated window title, process name, and match attribution into a secondary collapsible Details section.
  - Standardized video previews to a clean `16:9` widescreen container without black letterboxing.
- **Dashboard Layout Reorganization & Drives Simplification (Plan 061)**:
  - Reordered `DashboardView` so **Active Games on SSD** (with pinned games first) is the primary hero section at the very top.
  - Simplified and shrunk `DrivesOverview` cards to ~110px height with a single combined metrics row (`Library Games Storage • X GB (N games)` alongside percentage), compact 6px progress bar, and drive capacity footer.
- **App Update Feature Fixes (Plan 061)**:
  - Prevented error swallowing in `updater.ts` so check failures report actual errors rather than false-positive "latest version".
  - Added live inline status feedback (`updateStatus`) with semantic icons directly adjacent to the "Check for Updates" button in Settings.
  - Fixed `install_update_now` in Rust: prevented prematurely terminating `zapp-core.exe` at download start, safely deferring core termination to `on_before_exit` when NSIS runs. Cleanly stopped core on `relaunch_app`.
